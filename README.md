# Prácticas de SQL

Repositorio destinado a documentar ejercicios y prácticas de análisis y consulta de datos mediante SQL.

## Tecnologías utilizadas

- Python
- Pandas
- SQLite3
- SQL

## Práctica: Análisis de ventas tecnológicas

### Dataset

Se trabaja con un conjunto de datos de ventas de productos tecnológicos que contiene información sobre:

- Identificador de venta.
- Producto.
- Categoría.
- Precio unitario.
- Cantidad vendida.
- Fecha.
- País.

### Consultas SQL implementadas

1. **Selección simple:** selección de productos y precios con ordenamiento alfabético.
2. **Filtrado crítico:** identificación de ventas realizadas en Colombia con precios superiores a 500.
3. **Búsqueda de nulos:** identificación de registros con categorías sin información.
4. **Análisis de rendimiento:** cálculo de ingresos totales por categoría mediante `SUM()` y `GROUP BY`.
5. **Filtro de élite:** filtrado de categorías con ingresos superiores a 10.000 mediante `HAVING`.

## Objetivo

Practicar los fundamentos de SQL, la consulta de bases de datos y la manipulación de información para análisis de datos.
